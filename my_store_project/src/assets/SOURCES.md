# 图片来源说明（src/assets）

本目录的图片分两类，均与 `README.md` 里的「固定文件名」一一对应，`assetUrl.ts` 会自动收集。

## 一、商品图 `products/*.png`

- **来源**：项目内使用 Python（Pillow）绘制的「手帐平铺」插画，按 15 个商品的主题分别构图：
  牛皮纸本、计划本、四季/咖啡/食物贴纸、莫兰迪胶带、票据胶带、木质印章、针管笔、马克笔、
  电子素材、旅行本、格子胶带、日期印章、排版模板等。
- 图案里用到的彩色图标来自 Windows 系统自带的 Segoe UI Emoji 字体（`seguiemj.ttf`），
  属于系统字体渲染结果，没有引入第三方图库照片。
- **规格**：800 × 1000 px PNG，单张 210 ~ 285 KB（≤ 300 KB）。
- 为什么不用图库照片：当前开发环境的网络只放行了部分图片 CDN，Unsplash / Pexels / Pixabay
  的搜索页与 API 均被拦截，无法按关键词稳定检索并下载可商用照片；为保证 17 张商品图
  风格统一、与商品信息对应且可离线构建，这里改用本地生成的插画。
  以后网络可用时，按同名文件替换成实拍图即可，不需要改代码或数据库。

## 二、卖家头像 `avatars/*.png`

- **来源**：`https://randomuser.me/api/portraits/` 的演示人像（免费用于 demo / mockup）。
- 下载后居中裁成正方形并缩放到 96 × 96 px PNG（每张 14 ~ 21 KB）。
- 对应关系见 `README.md`：`avatar-1.png` → 纸间手作，……，`avatar-6.png` → 电子手帐研究所。

## 三、替换建议

- 想换成真实商品照：保持文件名不变，直接覆盖同名 PNG；建议先裁成 4:5（800 × 1000），
  再用 `pngquant` / TinyPNG 压到 300 KB 以内。
- 想换成品牌 logo 头像：同样覆盖 `avatar-N.png`，96 × 96 即可；缺失时页面会自动回退成昵称首字。
