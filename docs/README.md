# Final_Project_for_cloudhouse

## 产品需求部分（PRD）
### 产品概述

一个专注手账文创产品的网络集市，帮助用户极简购物，选到自己喜欢的手账产品。
### 目标用户

喜欢设计、喜欢记录生活、希望淘到心水手账工具的爱好者
### 功能实现优先级（模块化coding规划的第一步）
+ 基础功能
    - 搜索+筛选商品功能
    - 购物车功能
    - 提交订单+查看订单状态功能
+ 后续可开发功能
    - 内置智能ai导购员
    - 用户注册登录功能
    - 用户主页相关
### 界面设计大致描述与组件构成
+ 整体风格
    - 页面卡片模块采用标准圆角
    - 页面支持风格切换
        - 日间模式：#F5F5F7背景搭配#FFFFFF卡片
        - 夜间模式：#171918背景搭配#000000卡片
+ 首页
    - 网站顶部导航栏
        - 商品分类
        - 个人主页
        - 主题切换
    - 商品推荐区域
    - 商品列表
    - 商品搜索入口
    - 底部导航栏
        - 首页入口
        - 购物车入口
        - 个人主页入口
        - ai手账助手悬浮窗
+ 购物车
    - 购物车商品列表
+ 结算页面
    - 收货信息
    - 商品清单
    - 金额信息
+ 个人主页
    + 用户信息
    + 收藏商品列表
    + 商品列表（目前普通用户和卖家尚未分开，每个人都可以卖东西） 
### 部分数据说明
  + 订单号生成：采用14位时间戳+6位随机数生成
  + 用户密码哈希：加盐+慢哈希






## 技术栈
- 前端：React+Vite+npm
- 后端：Node.js+Express+MySQL
