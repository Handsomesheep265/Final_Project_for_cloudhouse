    + 未登录和已登录时的购物车是否合并：从源头上解决问题，未登录状态下，点击底部导航栏购物车直接优先跳转登录/注册页
    + 重复点击：重复加购仅合并数量，不会产生多条product_id相同的记录

    +  库存回补相关：下单真扣库存，若取消订单则回滚。但是扣减库存是带stock>=quantitiy条件的，防止超卖。

    + 只有搜索商品全名时才能命中该商品怎么办:建索引时使用MySQL内置的ngram解析器，将中文字段切分
    + 同时支持搜索店铺寻找商品：为users表的nickname（用户/店铺昵称）字段也建了一个索引

    +  token持久化的实现：每次打开自动续期，登录一次就不用再登
    +  退出登录立即吊销旧token：保证用户退出登录后，旧token已被拉入黑名单，下次需要重新登录

    +  找回密码：可通过邮箱找回密码，填写邮箱申请链接，打开链接即可设置新密码，邮件链接有效期为30分钟

## 技术栈
- 前端：React+Vite+npm
  + 为什么选择这套前端技术栈？
    + 尽管学习的是原生前端三件套。不过现代前端生态厚，能够帮助我快速搭建框架。
